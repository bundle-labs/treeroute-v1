If it stops (resume)
--------------------
  - Step 1 cannot resume part-way. It computes every site, then writes the three files at the end. Re-run the same
    command. Any partial files are moved to coral_data\_moved\<stamp>\full first (nothing is deleted). It says
    "nothing to rebuild" when all three files match their manifest.
  - Steps 2-7 take seconds to minutes: re-run the same command.
  - Step 8: re-run EXACTLY the same `run` command. The engine resumes the unfinished run of the same fingerprint from
    its saved phases (phases\<name>\DONE and its bank checkpoints) and does not redo finished phases. A finished run
    is refused. (`treeroute resume` is not built; re-running `run` is the resume.)
  - "stale heavy-job lock ... from dead pid" or "orphan engine temp file(s)": first check in Task Manager that no
    engine python runs. Then move (do not delete) D:\treeroute\tmp\treeroute_heavy_job.lock and the named temp files
    to D:\treeroute\runner_logs\stale_locks\, and re-run the same command.
  - A RAM or disk refusal: close programs or free space, then re-run the same command.
