  F2-F5 exactly as Part A section 3 (unchanged code): F2 link(y) = iso(x) | F3 link(y) - z0 = a + b (x - xbar) | F4
  link(y) - z0 = iso(x - xbar) | F5 per unit link(y) - z0 = a_u + b_u (x - xbar), shrunk to the pooled F3 with SHRINK_K
  = 10 rows (a unit with < 3 covered fit rows or unseen takes the pooled map, counted). z0 = the row's link-space
  normal (guard-cut ngd__ on tune / inner / guard-fit / guard rows; fit-cut nfit__ on refit and test rows). Isotonic
  direction = the Spearman sign of the pair the map fits. Squared error decides.
  F0 and F1 are NOT registered for the FWI rivals: FWI is an index (kind I, values 0 to ~220), not a burned fraction;
  F0 (pred = x) and F1 (x put inside the link's domain [0, 1] first) would read it as one. Same rule as the Part A
  I-kind rival crw_dhw (plan row "F0-F5", registry F2-F5). The plan's fire row (:69) reads "F0-F6": the owner confirms
  the F2-F6 list under OD-8 (section 11).
  F6 (fire only; identity link only; the ONE shared code edit, rivals_human/maps.py, spec 4.4; OD-14):
   - Fit rows: the covered labelled fit rows the tool passes (finite stat and y; board.fit_candidate drops the rest).
   - Cells c = (unit, season key = calendar month); n_c, S_c = count and sum of y per cell.
   - Normal check: a cell is complete when |S_c / n_c - z0_i| <= F6_NORMAL_TOL (1e-12) on every row of it (the slim's
     fit-row normal is the in-sample cell mean: measured max |difference| 1.1e-16). Rows in incomplete cells above
     F6_MAX_INCOMPLETE_SHARE (0.05) of the passed rows -> refuse (fail loud); below it they are dropped and counted.
   - Leave-year-out normal, as research C-A states it ("for train rows, N is the same normal formula computed leaving
     that year out"): N_loo_i = (S_c - y_i) / (n_c - 1), from the cell SUM. Rows with n_c < 2 or N_loo_i <= 0 are
     dropped and counted (and how many of them are burned).
   - Ratio r_i = y_i / N_loo_i. The pooled map and each group's map = isotonic fit of r on x with weights N_loo^2, i.e.
     argmin sum (y - N_loo r(x))^2 = squared error on the burned fraction (PLAN rule 5). Direction = the Spearman sign
     of (x, y) on the passed rows. A group needs >= MIN_FIT_ROWS (100) KEPT rows for its own map, else the pooled one;
     the kept rows must pass check_calibratable (>= 100 rows in >= 3 groups), else not calibratable.
   - Prediction = z0 x ratio(x), z0 = the scored rows' own slim normal (ngd__ on inner / guard rows, nfit__ on test
     rows; out of sample there), clipped to [0, 1] (pre-clip kept).
   - Recorded per fit (map json "info"): rows_passed, rows_kept, rows_incomplete_cell, rows_single_row_cell,
     rows_zero_loo_normal, rows_zero_loo_normal_burned, normal_check_max_abs_diff, weighted_level (= sum(N_loo y) /
     sum(N_loo^2) over kept rows).
   - Why (measured on lead-0 refit rows, all 40 groups, training labels only): with the in-sample normal the fitted
     level is 1.0 by construction against 0.846 out of sample (+18%); 2,192 of 14,834 burned rows are the only burn of
     their cell (ratio up to 16 in sample, out-of-sample normal 0); an unweighted ratio loss is ruled by tiny-N rows
     (unweighted leave-year-out mean ratio 1.58, max 1,080, against the target-optimal 0.846). If the owner declines
     (OD-14 b), F6 runs as the tool had it (in-sample normal, unweighted ratio) and section 10 discloses this effect.
