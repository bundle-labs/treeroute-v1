0. WHAT IS BUILT, IN ONE PICTURE
-----------------------------------------------------------------------------------------------------------------

  common export (lead L)  --slim-->  slim copy (keys, roles, train y, normals, history, named extras)
  product files on disk   --adapter-->  index table per rival x lead (x__<stat>, info_end, target_obs_end, src)
  slim + index tables     --check-->  identity, one row per key, timing rules T1/T2, manifests
                          --tune-->   calibration candidates fitted on tune rows, scored on inner rows (lead 0)
                          --lock-->   picks + coverage masks + hashes, write-once (before any test label)
                          --refit-->  per lead: guard (N2) + refit + test predictions raw and guarded
                          --score-->  the ONE reader of test y; engine metrics; verdicts; reference rows
                          --join-->   common board + human board -> ONE rival table

Plain idea: the human tool is a thin layer. It borrows from the signed common harness everything that decides a
score (run facts, export reading rules, guard, comparators, metrics, contrasts). It adds only what a product needs:
an index table, a small fixed family of calibration maps, coverage, and the joiner.

1.6 Calibration maps and the inner-MAE pick (PROT H6 :146-171; Q19 a; Q13; HQ6 a)

  Notation: z = link-space prediction; z0 = the row's link-space normal (ngd__ on tune/inner/guardfit/guard rows,
  nfit__ on refit/test rows; PROT H4); c = the run's c of the lead (H:502-509); xbar = the index's own mean per
  unit x season key over the same fit rows (a unit with < 3 covered rows in a key uses the pooled key mean; season
  key from the export manifest `season`, e.g. coral event_month).
    F0 native       pred = x                                       N kind and M kind only (no fit)
    F1 lin_link     link(y) = a + b*link(x)   OLS                   N only
    F2 iso_raw      link(y) = iso(x)                                I, N, and defo calibrated form
    F3 lin_anom     link(y) - z0 = a + b*(x - xbar)  OLS            I, N
    F4 iso_anom     link(y) - z0 = iso(x - xbar)                    I, N, and defo calibrated form
    F5 unit_mos     link(y) - z0 = a_u + b_u*(x - xbar), per unit, a_u and b_u shrunk toward the pooled F3
                    (a, b) with SHRINK_K = 10 (A4); a unit with < 3 covered fit rows uses the pooled F3 map
                    (counted, disclosed: PLAN R12)                  I, N
    F6 (Part B, fire only) normal x per-group isotonic ratio of a per-unit percentile stat (PLAN :69). Built
                    generic ("percentile stat x per-group ratio"), enabled only by a registry that lists it.
  Rules: maps fitted per lead on that fit set's covered rows with finite y and x; no weights; links = every R22
  link of the run (F0 has none); isotonic direction = sign of Spearman of the pair the map fits on the same rows (F2: x vs y; F4 and the anomaly L1 map: x - xbar vs link(y) - z0; review 2026-10-22 issue 5) (recorded);
  sklearn IsotonicRegression(increasing=<sign>, out_of_bounds="clip"), squared error; back-transform with
  link_inverse, no smearing; clip with clip_to_legal, keep pre-clip (PROT H9). Minimum to fit: >= 100 covered
  labelled rows in >= 3 groups (Q2.HQ9); below that "not calibratable at this lead": no row, disclosed.
  Candidates per rival = stats (<= 3) x allowed families x links. The PICK = lowest inner MAE of the clipped
  prediction on the inner rows the rival covers (lead 0); ties broken by the fixed order (stat order, family
  F0..F6, R22 link order). corr2, calibration ratio and predict-zero MAE are logged beside each candidate.
  A forecast-only product (no nowcast form; today coral Outlook) is picked on the guard rows of its lowest covered
  lead, pre-registered (Q2.HQ10). One pick per rival, PINNED at every lead, refit per lead (Q2.HQ10 a).
  L1 print (Q13): when the run's legal_min == 0 and the lead-0 refit zero share >= TWEEDIE_ZERO_SHARE (H:90;
  data-driven: today coral and defo in Part A), the picked candidate is refit once more with an L1 (weighted
  median, pool-adjacent-violators) isotonic map and printed beside. It never decides.
  M kind (published method): output as shipped, F0 only (PROT H7), except defo where both forms are rivals (1.9).
