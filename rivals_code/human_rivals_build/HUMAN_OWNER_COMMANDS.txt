=====================================================================================================================
0. HOW THIS FITS AROUND THE COMMON RIVAL RUNS
=====================================================================================================================
- Every human command (except `status`) takes the ENGINE heavy-job lock (the production config names the engine's
  machine file). So a human command simply REFUSES while a common rival command (or an engine run) is working:
  "REFUSED: ... heavy-job lock ...". You never run both at once; run human steps in the gaps.
- Common order (RIVALS_OWNER_COMMANDS.md): coral DONE, fire DONE, pm25 RUNNING NOW (export, 2026-10-22), then defo,
  then NDVI one lead at a time. The human steps below are placed in that order.
- COPY BEFORE DELETE: a human `slim` copy must be made from each common export lead BEFORE you delete that export
  folder (RIVALS_OWNER_COMMANDS.md section 7). Coral's export is still on disk: slim it at the first gap.
- DISK: D: had 15.4 GB free on 2026-10-22. The defo common export needs ~8.5 GB + ~6.7 GB per lead, NDVI ~5.7 GB +
  ~10 GB per lead. Before defo: delete the scored fire export (0.4 GB) and, once the pm25 common board is fully
  scored, the pm25 export and its fit-set copies (~4 + ~3 GB) (common section 7). The human tool itself adds little
  (x): slim copies ~0.1-1.5 GB per lead (NDVI largest), index tables < 0.3 GB per rival, defo prep work folder
  ~0.5-2 GB, Kraft store ~0.2 GB.
- RAM: close apps first. Human steps need < 2 GB, except the defo prep (O10/O11: ~6 GB with 3 workers) and the
  optional Kraft prep (3-5 GB).
- No human TEST score before Part A is signed (D:\treeroute\human_rivals_build\PREREGISTRATION_DRAFT_human_partA.txt).
  Steps 1-5 below read no test label; step 7 (refit, refs, score) comes after the signature.
