3. CALIBRATION MAPS AND THE PICK (SPEC_HUMAN 1.6; PROT H6; Q19 a, HQ6 a)
  F0 native pred = x | F1 link(y) = a + b link(x), x put inside the link domain first (>= 0; <= UB for arcsine) |
  F2 link(y) = iso(x) | F3 link(y) - z0 = a + b (x - xbar) | F4 link(y) - z0 = iso(x - xbar) |
  F5 per-unit link(y) - z0 = a_u + b_u (x - xbar), a_u, b_u shrunk toward the pooled F3 with SHRINK_K = 10 rows
  (A4): s* = (n_u s_u + K s_pool) / (n_u + K); a unit with < 3 covered fit rows (or unseen) takes the pooled map;
  a unit with no spread in x keeps the pooled slope (counted) | F6 (Part B only) normal x per-group isotonic ratio.
  z0 = the row's link-space normal (guard-cut ngd__ on tune / inner / guard-fit / guard rows, fit-cut nfit__ on refit
  and test rows). xbar = the index's mean per unit x season key over the same fit rows; a cell with < 3 rows takes the
  pooled key mean, an unseen key the pooled mean.
  Isotonic direction = sign of Spearman(x, y) on the fit rows (undefined -> increasing); sklearn IsotonicRegression
  (out_of_bounds clip), squared error, knots kept as JSON. No weights. Back-transform with link_inverse, no smearing;
  clip with clip_to_legal, pre-clip kept.
  Minimum to fit: >= 100 covered labelled rows in >= 3 groups, else "not calibratable at this lead" (no row,
  disclosed).
  Candidates = stats (<= 3) x families x R22 links (F0 has no link), fixed order (stat, family F0..F6, link).
  The pick = the lowest MAE of the clipped prediction on the pick rows covered by EVERY stat of the rival (so all
  candidates are compared on the same rows); ties by the fixed order. Nowcast rivals pick on lead-0 inner rows (fit on
  tune rows); a forecast-only product picks on the guard rows of its lowest covered lead (fit on guard-fit rows).
  corr2, calibration ratio and predict-zero MAE are logged beside every candidate (trials.csv).
  One pick per rival, pinned at every lead, refit per lead. M rivals with a runner have one configuration (no pick).
  L1 print (Q13): when the run's legal minimum is 0 and the lead-0 refit zero share is >= 0.20 (data rule; today
  coral and defo), the pick's L1 isotonic map (raw form for F0-F2 picks, anomaly form for F3-F5) is refit and printed
  beside as l1_raw_vs_raw. It never decides. When x has more than 20,000 distinct values the L1 map uses 20,000
  equal-count rank blocks.

5. COVERAGE, SAFETY NET, VERDICTS
  Coverage mask per lead (HQ3 a): test rows where the picked stat is finite in the index (rivals written in one go),
  or the registry's label-free rule (rivals that read the target in the test window, and runners): all_rows or a
  mapping (issue_min / issue_max / units column / a label-free function). Written at the lock, hashed. A staged index
  must later cover every locked row, else refit refuses.
  Safety net (HQ2 a): lead 0 guard = the pick fitted on tune rows, scored on its covered inner rows; lead L = fitted on
  covered guard-fit rows, scored on covered guard rows. Comparator on the same rows = the run's own saved
  <link>_trees_off_unweighted of the pick's link (F0 and methods: identity), or the donor-row median (neighbour kind,
  V1). Passed iff MAE(rival) < MAE(comparator) strictly (n2_eligible). guarded = raw if passed, else the run's decline
  target. score_without_net leads: guarded = raw, flagged "no safety net".
  Deciding contrast: covered rows of groups with >= 10 covered test rows, ours on the same rows; d_g = MAE_rival(g) -
  MAE_ours(g); contrast_tag with the run's nowcast band at every lead; BEATS / LOSES / EQUIVALENT / CANNOT TELL;
  blocked jackknife (R14) beside; timid flag. guarded_vs_headline decides (tiers P, L); raw_vs_raw printed. Beside:
  rows k of n, groups, years, our all-row MAE, the normal's MAE on the same rows, a "filled" line (uncovered rows take
  the decline target; never decides), per-stratum and unseen-unit tables, and the resolution-matched table for coarse
  products (printed only).
  A tier-L BEATS is worded with its label ("beats NOAA's nowcast rule fed old heat"), never "beats NOAA".
